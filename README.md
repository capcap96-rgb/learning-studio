# 學習練習台

繁體中文個人學習網站，支援 GitHub Pages、Google Drive 同步，以及手機／電腦的字體大小偏好。

## v1.2.1 錄音連結

- 每次打卡最多 3 則錄音連結，可填名稱；同一天打卡次數與連結總數不設上限。
- Pixel 錄音工具分享連結後貼上；歷史紀錄另開 Google Recorder（或原連結）回聽，不嵌入播放器、不傳送音訊或自動讀取錄音。
- 舊版單一錄音連結仍可顯示、編輯、備份與還原。編輯儲存時轉成新格式；移除附件只移除打卡中的連結，不刪除原錄音。
- 更新後請手機與電腦都重新整理至 V1.2.1，再編輯錄音附件，避免舊版編輯器遺漏新增連結。

## 口說訓練打卡

- 依每日打卡單整理 24 天主課程與 6 次延伸練習，包含課程影片、零碎時間聆聽、詩組／高能句／對話或指定作業。
- 課程天數與實際日期分開，可分次完成同一課，也能一天練多次；每次訓練獨立保存。
- 保存日期、時間、分鐘數、本次完成事項、跟練遍數、心得與自己的錄音連結。網站不提供課程影片或詩文，也不會上傳錄音。
- 累積清單勾選計算每課進度；重練增加次數與時間，不重複增加完成課數。
- 歷史支援日期／課程篩選、編輯、刪除與還原。刪除是可還原的標記，統計只計未刪除紀錄。
- 可以另建新一輪課程重新挑戰，前一輪資料保留。
- 今日頁提供繼續練習入口，每週回顧整合口說次數、時間與天數，不與一般練習紀錄重複計算。

## 開始使用

1. 更新前先從「同步與備份」匯出一份 JSON。手機與電腦都重新整理到 V1.2.1 後，再使用新打卡功能。
2. 選「口說打卡」，建立一輪課程；可歸屬既有計畫，或自動建立新的口說學習計畫。
3. 選擇要練的課程、實際日期時間，填入分鐘數並勾選本次完成事項，按「儲存本次訓練」。
4. 在「同步與備份」連接相同 Google 帳號，按立即同步；也可選擇已連線時自動同步。
5. 在另一裝置開啟同一網址、連接同一帳號並同步，即可接續使用。

## 資料與相容性

學習備份保留根層 `version:1`；新打卡資料放在可選的 `speaking` 欄位，其格式為 `version:1`、`courses` 與 `logs`。舊備份缺少此欄位仍可讀取，沒有使用打卡功能時不會自動新增或改寫資料。

Google Drive 保存完整資料快照，打卡紀錄、刪除標記及舊的學習資料會一起同步。使用 `drive.appdata`，權杖只留在本頁記憶體；每次重新開啟須再連接。網站關閉後不執行背景同步。兩個裝置同時修改時須選擇完整版本，不會逐欄自動合併；請先下載兩份備份保留內容。

PDF 原檔、課程媒體、個人學習紀錄與錄音檔不包含在此儲存庫。Client ID 為公開的 OAuth 應用程式識別碼；不需要 Client Secret。

## 程式與驗證

靜態 HTML/CSS/JavaScript，無建置步驟。`speaking.js` 包含清單、紀錄驗證、統計與打卡畫面；`drive.js` 負責 Google Drive 同步；`app.js` 負責主網站整合。

使用 Node.js 24 執行測試：

```sh
node --test tests/speaking.test.cjs tests/sync.test.cjs
```

目前有 40 項測試，涵蓋清單對應、分次完成、重練、編輯／還原計算、舊備份相容、表單提交、同步分歧與斷線等。尚未完成此版本的瀏覽器視覺及真實帳號跨裝置驗證，測試使用模擬的 Drive 介面，不連線個人雲端。

## 更新流程

以功能分支提交 Pull Request，由擁有者檢視並手動合併至 `main`，GitHub Pages 再自動發布。請勿直接把使用者資料或權杖提交到 GitHub。
